## Mission

Veyqra soll die einfachste Möglichkeit werden, moderne Bild-KI lokal oder in der Cloud zu nutzen.

Der Benutzer soll sich auf Kreativität konzentrieren.

Nicht auf:

- Python
- CUDA
- AWS
- Docker
- SSH
- ComfyUI

Diese Komplexität übernimmt Veyqra.
